# TGproxycheck

TGproxycheck проверяет Telegram-прокси на Windows и в Termux. Программа принимает MTProto, WEB proxy, SOCKS5 и HTTP/HTTPS CONNECT, показывает понятный результат и сохраняет подробный отчёт.

Текущий релиз сохраняет версию приложения `1.3.0`.

## Что происходит при проверке

1. Ссылка разбирается и приводится к единому виду. Поддерживаются `tg://proxy`, `t.me/proxy`, `tg://webproxy`, `tg://socks`, SOCKS5 URL, HTTP/HTTPS CONNECT URL и прокси, найденные внутри JSON или обычного текста.
2. Проверяется секрет MTProto или WEB proxy: формат HEX, длина, варианты `Classic`, `DD/Padded` и `EE/Fake-TLS` с SNI.
3. Домен разрешается через системный DNS. Если он недоступен, используется DoH. Повторные запросы берутся из кеша.
4. Измеряются TCP-доступность, задержка, jitter и потери.
5. Для MTProto выполняется настоящий `req_pq` через AES-CTR transport с проверкой nonce и структуры ответа Telegram. Для SOCKS5 и HTTP проверяется тот же Telegram-протокол через туннель.
6. Для Fake-TLS отдельно проверяются SNI, DNS и TLS-ответ прикрывающего домена.
7. IP и SNI сопоставляются с диапазонами Telegram и базой совместимости БС. Это эвристика, а не гарантия работы у конкретного оператора.
8. При включённой геолокации добавляются страна, город, ISP, ASN, часовой пояс и признаки хостинга/VPN/прокси.
9. Итоговый score учитывает протокол, TCP, задержку, jitter, наличие IP и результаты дополнительных тестов.

## Собственные источники

Публичные списки можно дополнять своими источниками. Поддерживаются:

- прямые URL на TXT/JSON/CSV или текстовую страницу;
- локальные файлы TXT, JSON и CSV;
- отдельные `tg://`, SOCKS5 или HTTP proxy-ссылки.

Источники сохраняются в `custom_proxy_sources.json`. Дубликаты удаляются по нормализованной ссылке. Максимальный размер одного источника — 8 МБ.

В Windows откройте страницу «Публичные списки» и нажмите «Свои источники». Кнопка «Собрать и проверить» объединяет публичные и сохранённые источники. В окне «Отчёт источников» видны тип, статус, количество найденных и добавленных прокси.

В Termux управление доступно из меню или через CLI:

```bash
python3 TGproxycheckterm.py custom-sources list
python3 TGproxycheckterm.py custom-sources add "https://example.org/proxies.txt"
python3 TGproxycheckterm.py custom-sources remove 1
python3 TGproxycheckterm.py custom-sources clear
python3 TGproxycheckterm.py sources
python3 TGproxycheckterm.py sources --source "./my-list.txt"
python3 TGproxycheckterm.py sources --no-custom
```

## Windows-версия

Файл `PCsourcecode` содержит исходник Tkinter-приложения. Основные разделы интерфейса:

- одиночная проверка;
- пакетная проверка файла или буфера обмена;
- публичные и собственные источники;
- параметры таймаута, повторов, параллельности и геолокации;
- экспорт TXT, JSON и CSV.

Для запуска исходника нужны Python 3.11+ и пакеты:

```bash
pip install requests cryptography
python TGproxycheck.py
```

Готовый `TGproxycheck.exe` можно запускать без установленного Python.

## Termux-версия

Файл `Termuxsourcecode` содержит консольную версию с Rich-интерфейсом, интерактивным меню и CLI-командами.

```bash
pkg install python
pip install requests rich cryptography
python3 TGproxycheckterm.py
```

Для Telethon-проверок дополнительно нужны `telethon` и параметры клиентской сессии, если они используются вашей сборкой.

## Android APK

`TGproxycheck.apk` — отдельная Android-сборка. Она поддерживает те же основные сценарии проверки, включая пользовательские источники. Для изменения APK нужен Android-проект Kotlin/Compose; одного скомпилированного APK недостаточно для безопасной пересборки.

## Экспорт и результаты

TXT содержит читаемый отчёт и полный JSON каждого результата. JSON сохраняет сводку и все поля проверки. CSV подходит для сортировки и дальнейшего анализа.

Рабочий прокси означает, что Telegram-протокол подтвердил соединение в момент проверки. Сетевые условия меняются, поэтому результат не является постоянной гарантией доступности.
